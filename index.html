오늘의 체크리스트

    입력 · 설정

    값 일괄 입력

    입력한 칸만 저장됩니다. 저장하면 기존 현재 값은 자동으로 "직전 값"이 됩니다. 같은 기준일로 다시 저장하면 덮어씁니다. 지표 카드를 누르면 개별 수정·이력 삭제가 가능합니다.

    백업

    데이터는 이 기기 브라우저(localStorage)에만 저장됩니다. 기기 변경·브라우저 데이터 삭제 전에 내보내 두세요. API 키는 백업 파일에 포함되지 않습니다.

    자동 조회 (선택)

    FRED API 키를 넣으면 미국 금리·CPI·실업률·VIX·유가·원/달러 등 일부 지표를 자동으로 가져옵니다. 키는 이 기기 localStorage에만 저장됩니다. 브라우저 보안(CORS) 때문에 직접 호출이 막히면 프록시 URL이 필요합니다(README 참고).
