오늘의 체크리스트

    매크로 인사이트 규칙 기반 일반 해석

    입력 · 설정

    자동 데이터

    GitHub Actions가 정해진 시간마다 FRED·Yahoo Finance·한국은행에서 값을 받아 사이트와 함께 배포합니다. API 키는 GitHub 저장소 Secrets에만 있고 이 기기에는 저장되지 않습니다.

    값 직접 입력

    자동 수집이 안 되는 지표(리튬 등)를 입력하거나 자동 값을 덮어쓸 때 사용합니다. 입력한 칸만 저장되고, 같은 기준일 값이 있으면 직접 입력이 우선합니다. 지표 카드를 누르면 개별 수정·삭제가 가능합니다.

    백업

    직접 입력한 값은 이 기기 브라우저(localStorage)에만 저장됩니다. 기기 변경·브라우저 데이터 삭제 전에 내보내 두세요. 자동 데이터는 백업할 필요가 없습니다.

    화면

    데이터 관리

    신호등 임계값·코멘트·체크리스트 규칙은 index.html 상단의 CONFIG, 자동 수집 소스는 scripts/sources.mjs에서 수정합니다.
    정보 정리용이며 투자 권유나 매매 판단이 아닙니다.
