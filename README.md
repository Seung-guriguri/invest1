# 매크로 대시보드

금리·물가·경기·신용·환율·원자재 **87개 지표**를 한 화면에서 보는 **모바일용 개인 대시보드**입니다.
GitHub Actions가 하루 3번 FRED·Yahoo Finance·한국은행에서 데이터를 자동으로 받아 GitHub Pages에 배포하고,
휴대폰에서는 홈 화면 앱(PWA)으로 열어 보기만 하면 됩니다.

> 정보 정리용이며 투자 권유나 매매 판단이 아닙니다.

## 파일 구조

```
index.html                      화면 + 스타일 + 앱 로직. 스크립트 상단 CONFIG / COMMENTS / CHECKLIST (임계값·해설·규칙)
prompts/ai-system.md, ai-user.md  AI 인사이트 프롬프트 (역할·규칙 / 데이터 틀)
prompts/ai-column.md            오늘의 칼럼 프롬프트 (브리핑을 종합한 스토리텔링 칼럼)
scripts/ai-insight.mjs          AI 인사이트 생성 (Gemini, 하루 1회)
notes.js                        지표별 인사이트 문구 (의미·함께 볼 지표·확인할 것)
season.js                       계절 요인 메모 (카드의 "🗓 지금은 ○○ 시기", AI 브리핑 프롬프트에도 사용)
data.js                         데이터 모듈: 자동 데이터(data/latest.json) + 직접 입력(localStorage) 병합, 백업
scripts/sources.mjs             지표별 자동 수집 소스 (FRED 시리즈, Yahoo 심볼, 한국은행 통계코드)
scripts/fetch-data.mjs          수집 스크립트 (Node 18+, 외부 패키지 없음). 계산 지표(크랙 스프레드·한미 금리차 등)도 여기서
scripts/alerts.mjs              긴급 경고 판단(정제 가동률 급락 등) + 선택적 텔레그램 알림
.github/workflows/update-data.yml  정기 수집 + Pages 배포 워크플로
manifest.json, sw.js, icons/    PWA (홈 화면 설치, 오프라인 열람)
```

`data/latest.json` 은 Actions가 배포할 때 만들어 함께 올리며, 저장소에는 커밋하지 않습니다.

## 1. 자동 데이터 설정 (처음 한 번)

### ① FRED API 키 받기 (무료, 5분)

FRED는 미국 세인트루이스 연방준비은행이 운영하는 경제 데이터베이스입니다. 이 대시보드의 미국 금리·물가·고용·신용 지표가 여기서 옵니다.

1. https://fred.stlouisfed.org 접속 → 오른쪽 위 **My Account** → **Create New Account**
   (이메일·비밀번호로 가입, 또는 Google 계정 로그인)
2. 로그인 후 API 키 페이지로 이동: https://fredaccount.stlouisfed.org/apikeys
   (메뉴: My Account → **API Keys**)
3. **Request API Key** 클릭
4. 사용 목적 설명란에 간단히 입력 — 예: `Personal dashboard for tracking macroeconomic indicators`
5. 약관 동의 체크 → **Request API key**
6. 바로 **32자리 영숫자 키**가 표시됩니다 (예: `abcd1234...`). 복사해 두세요.
   키는 같은 페이지에서 언제든 다시 확인할 수 있습니다.

> 무료이며 요청 한도(분당 120회)는 이 대시보드(하루 3회 × 약 40건)에 충분합니다.

### ② 한국은행 ECOS 키 받기 (선택, 한국 지표용)

한국 기준금리·국고채 3년/10년·한국 CPI를 자동으로 받으려면 필요합니다. 없으면 한국 CPI·국고채 10년은 FRED(OECD, 월간·지연)로 대체되고, 기준금리·국고채 3년은 직접 입력해야 합니다.

1. https://ecos.bok.or.kr/api/ 접속 → 오른쪽 위 **회원가입** 후 로그인
2. 상단 **인증키 신청** → 이용 목적(예: 개인 학습·대시보드) 입력 → 신청
3. **마이페이지 → 인증키 발급 내역**에서 키 확인 (보통 바로 발급)

### ②-1 EIA 키 받기 (선택, 미국 에너지 수급 지표용, 1분)

천연가스 저장량·쿠싱 재고·정제 가동률·원유 생산·휘발유/디젤 수요·원유 순수입을 받으려면 필요합니다. 없으면 이 7개만 "데이터 없음"으로 표시됩니다.

1. https://www.eia.gov/opendata/register.php 에서 이름·이메일 입력, 약관 동의 → **Register**
2. 메일로 온 API 키 복사

### ③ GitHub에 키 등록 (Secrets)

키는 코드에 넣지 않고 저장소의 비밀 저장소에만 둡니다. 브라우저·휴대폰에는 저장되지 않습니다.

1. GitHub 저장소 → **Settings** → 왼쪽 **Secrets and variables** → **Actions**
2. **New repository secret**
   - Name: `FRED_API_KEY` / Secret: FRED 키 붙여넣기 → **Add secret**
3. (선택) 한 번 더 **New repository secret**
   - Name: `ECOS_API_KEY` / Secret: 한국은행 키
4. (선택) `EIA_API_KEY` / Secret: EIA 키

### ④ GitHub Pages를 "GitHub Actions" 방식으로 켜기

1. 저장소 → **Settings** → **Pages**
2. **Build and deployment → Source** 를 **GitHub Actions** 로 선택 (Deploy from a branch 아님)

### ⑤ main 브랜치에 반영하고 첫 실행

- 워크플로는 **main 브랜치**에 push될 때, 그리고 정해진 시간마다 실행됩니다.
  작업 브랜치에서 만들었다면 Pull Request로 main에 합치세요.
- 바로 실행하려면: 저장소 **Actions** 탭 → 왼쪽 **데이터 수집 및 배포** → **Run workflow**
- 1~3분 뒤 완료되면 `https://<사용자명>.github.io/<저장소명>/` 에서 열립니다.
- 실행 로그의 "지표 수집" 단계에서 지표별 ✓ / ✗ 결과를 볼 수 있습니다.

### 수집 시간 (한국시간)

| 시간 | 목적 |
|---|---|
| 07:23 (월~금) | 미국 장 마감 후 시세 + **AI 인사이트 생성(하루 1회)** |
| 16:43 (월~금) | 한국 장 마감 후 시세·환율 |
| 22:13 (월~금) | 미국 경제지표 발표(대개 21:30~23:00) 반영 |
| 07:23 (토) | 금요일 미국 장 마감 반영 (데이터만, AI 없음) |

데이터 수집은 AI를 쓰지 않으며 무료 API·무료 Actions(공개 저장소)로 돌아가 비용이 없습니다. AI(Gemini)는 평일 07:23 한 번만 부릅니다.

`.github/workflows/update-data.yml` 의 `cron` 으로 바꿀 수 있습니다 (UTC 기준, 한국 = UTC+9).
GitHub 예약 실행은 몇 분~수십 분 늦을 수 있습니다.
공개 저장소는 60일간 활동이 없으면 예약 실행이 꺼지는데, 워크플로의 `keepalive` 단계가 예약 실행 때마다 다시 켜 두도록 해 두었습니다.
그래도 Actions 탭에 비활성화 안내가 보이면 **Enable workflow**를 눌러 주세요.

Yahoo 시세는 수집 시점에 정규장이 열려 있으면 그날 봉(장중 가격)을 빼고 **직전 종가까지만** 저장합니다.

## AI 인사이트 (Gemini, 하루 1회)

- 평일 **07:23(한국시간)** 수집 때 Gemini를 한 번 호출해 **오늘의 AI 브리핑**(홈 화면 맨 위), **분류별 브리핑**(금리·물가·에너지 등 11개 분류마다 한 줄 제목 + 5줄 이내 이야기. 홈 브리핑 카드에서 눌러 펼치고, 각 탭 맨 위에도 표시)과 크게 움직인 지표 최대 15개의 **AI 해설**(지표 상세의 인사이트 안)을 만듭니다.
- 나머지 수집(16:43, 22:13)과 코드 배포 때는 다시 부르지 않고 아침 해설을 그대로 씁니다. 다시 만들려면 Actions → **데이터 수집 및 배포** → **Run workflow** → "AI 인사이트도 새로 생성"을 체크합니다.
- 설정: 저장소 Secrets에 `GEMINI_API_KEY`. (선택) Variables에 `GEMINI_MODEL` — 비우면 사용 가능한 Flash 계열을 자동 선택.
- **프롬프트는 `prompts/` 에서 수정**합니다. 코드 수정 없이 다음 실행부터 반영됩니다.
  - `prompts/ai-system.md` — **리서치 요청서(다중 지표 융합·국면 분류·상충 신호·시나리오 방법론)** + 이 앱의 전달 규칙(쉬운 말·정확성·금지 원칙) + 출력 형식. 결과는 브리핑·분류별 요약·지표 해설과 **📊 리서치 리포트**(국면·핵심 결론·통합 인사이트·상충 신호·1~3개월 시나리오·모니터링·최종 판단)
  - `prompts/ai-user.md` — 데이터 틀 (지표별 현재값·1개월/3개월/1년 변화·변화의 이례성·분포 위치·평년 대비)
- 안전장치: 투자 권유·매매 지시 표현이나 내부 필드 이름(z_1m 등)이 들어간 문장은 자동으로 빼고, '사상 최고'는 '최근 수년 중 최고'로 고칩니다(분포 위치는 최근 2~10년 기준이므로). 호출 실패·한도 초과·형식 오류 때는 이전 해설을 유지합니다. 화면에는 "AI 생성 · 모델 · 생성 시각 · 틀릴 수 있음"이 함께 표시됩니다.
- 생성 결과 전문과 길이 점검 결과가 Actions 로그(AI 인사이트 단계)에 그대로 남아 검토할 수 있습니다.
- 무료 등급에서는 보낸 내용(공개 시장 데이터)이 Google의 서비스 개선에 쓰일 수 있습니다. 개인이 직접 입력한 값은 보내지 않습니다.

## 긴급 경고 (정제 가동률 급락 · 하이일드 스프레드 급확대 · VIX 급등)

- 수집 때마다(하루 3번) `scripts/alerts.mjs` 가 판단해 `data/alerts.json` 을 만들고, 앱 맨 위에 **빨간 배너**와 체크리스트 1순위로 띄웁니다.
- **정제 가동률 급락**
  - 🚨 긴급: 한 주 −3%p 이상, 또는 이번 주도 하락 중이면서 3주 누적 −5%p 이상 (허리케인·사고·정전 등 설비 차질 신호)
  - ⚠ 주의: 한 주 −2%p 이상, 또는 이번 주도 하락 중이면서 3주 누적 −3.5%p 이상
  - 정기 정비 시즌(2~4월, 9~10월)에는 계획된 하락이 흔해 3주 누적 기준을 −7%p(긴급)·−5%p(주의)로 높여 오경보를 줄입니다.
  - 배너에 크랙 스프레드 변화, 디젤·휘발유 재고(평년 대비), 정비 시즌 여부가 함께 표시됩니다.
- **하이일드 스프레드 급확대** (일간)
  - 🚨 긴급: 최근 5거래일 저점 대비 +0.75%p, 또는 1개월 저점 대비 +1.5%p
  - ⚠ 주의: +0.4%p / +0.8%p (이미 하루 −0.1%p 이상 되돌리는 중이면 제외)
- **VIX 급등** (일간)
  - 🚨 긴급: 30 이상이면서 5거래일 저점 대비 +50%, 또는 40 이상, 또는 하루 +50%(25 이상일 때)
  - ⚠ 주의: 22 이상이면서 5거래일 저점 대비 +30%, 또는 하루 +25%(18 이상일 때)
- **휴대폰 알림 (선택, 텔레그램)** — 긴급 경고가 새로 생기면 보냅니다. 경고가 이어지는 동안은 다시 보내지 않고, 같은 경고는 72시간 안에 다시 보내지 않습니다. ⚠ 주의 단계는 앱 배너에만 표시합니다.
  - 텔레그램이 설정돼 있으면 **평일 아침 AI 브리핑**(제목·이야기·핵심 수치·한국 관점·확인할 것·분류별 한 줄)도 함께 보냅니다.
  - 이어서 **📊 매크로 리서치 리포트**(길면 여러 메시지로 나눠 보냄)와 **📰 오늘의 칼럼**(브리핑을 종합한 1,200~1,600자 스토리텔링 칼럼, 소제목 2~3개)도 보냅니다. 앱에서는 AI 브리핑 카드의 '오늘의 칼럼'을 눌러 읽을 수 있습니다. 칼럼은 Gemini를 한 번 더 부르며(약 6~8천 토큰), 실패해도 브리핑은 그대로 보냅니다. 문체는 `prompts/ai-column.md` 에서 바꿉니다.
  1. 텔레그램에서 `@BotFather` → `/newbot` → 봇 토큰 받기
  2. 저장소 Settings → Secrets and variables → Actions 에 `TELEGRAM_BOT_TOKEN` 등록
  3. 텔레그램에서 만든 봇을 열고 **시작(/start)** 을 누름
  4. 24시간 안에 Actions → 데이터 수집 및 배포 → Run workflow → **"텔레그램 알림 연결 테스트"** 체크 후 실행
     → 봇이 "연결 성공" 메시지와 **채팅 ID** 를 보내 줍니다
  5. 그 숫자를 `TELEGRAM_CHAT_ID` Secret 으로 등록 (등록 전에도 24시간 동안은 자동으로 찾아 보냄)
  - 설정하지 않으면 앱 배너로만 표시됩니다.
- 새 경고 규칙은 `scripts/alerts.mjs` 의 `RULES` 에 추가합니다.

- "Yahoo → FRED" 는 Yahoo를 먼저 시도하고 실패하면 FRED로 대체한다는 뜻입니다. 한 지표의 시계열은 한 소스에서만 가져와 섞지 않습니다.
- ETF와 해운주(FRO·STNG·FLNG)·BDRY는 배당·분할을 반영한 **수정종가**를 씁니다 (배당락일 가짜 급락 방지).
- ETF 전체와 해운주·ETF 대용 지표(BDRY·FRO·STNG·FLNG)는 '주의' 단계 없이, 하루 ±5% 이상 움직일 때만 빨간 **급등/급락** 표시를 합니다.
- ETF는 매크로 흐름을 보여주는 참고 지표이며 투자 추천이 아닙니다. 선물 기반 ETF(DBC·DBA·BWET·UNG 등)는 롤오버 비용 때문에 실제 원자재 가격과 장기적으로 벌어질 수 있습니다.
- 단위: 구리·곡물은 Yahoo 선물 가격(¢/lb, ¢/bu)을 **$/t로 환산**해 IMF 월간 값과 단위를 맞췄습니다.
- 월간·분기 지표(CPI, 고용, GDP, IMF 원자재 등)는 발표 주기상 기준일이 1~2개월 전인 것이 정상입니다.
- 이번 수집에서 실패한 지표는 **이전 배포 값을 유지**하고, 오래 갱신되지 않으면 "오래된 데이터" 경고가 뜹니다 (기준은 4장 참고).
- **Yahoo Finance는 비공식 API**라 예고 없이 막히거나 형식이 바뀔 수 있고, 이용 약관상 개인적·비상업적 용도로만 쓰세요.

### 지표 추가·소스 변경

1. `scripts/sources.mjs` 에 `새id: [{ fred: '시리즈ID' }]` 추가
   - FRED 시리즈 ID는 fred.stlouisfed.org 에서 검색한 페이지 주소 끝부분 (예: `.../series/DGS10` → `DGS10`)
   - 전년비로 받으려면 `units: 'pc1'`, 전기 대비 차이는 `'chg'`, 단위 환산은 `scale`
   - Yahoo는 finance.yahoo.com 의 심볼 (예: `^GSPC`, `CL=F`, `KRW=X`)
   - ECOS는 통계표 코드·항목 코드·주기 (ECOS 웹 "통계코드검색"에서 확인)
2. `index.html` 의 `CONFIG.indicators` 에 같은 `id` 로 이름·단위·임계값 추가
3. main에 push → Actions가 수집·배포

로컬에서 수집만 시험하려면:

```bash
FRED_API_KEY=키 ECOS_API_KEY=키 node scripts/fetch-data.mjs --out data/latest.json
python3 -m http.server 8000   # http://localhost:8000
```

## 3. 화면 사용법

- **요약**: 경고/주의/양호/오래됨 개수, **오늘의 체크리스트**(규칙 기반 3~5개, 체크 상태는 당일만 유지)
- **매크로 인사이트**: 여러 지표가 함께 가리키는 흐름을 최대 3개까지 짧게 해석
  - 예: 고금리 장기화(10년물 4.75% 이상이 3개월 지속), 신용 여건 악화, 경기 둔화, 물가 재가속, 달러 강세·원화 약세, 석유 재고 완충 축소, 낙관 국면
  - 각 인사이트: 현재 수치 한 줄 · 해석 2~4줄 · 점검할 것 · 관련 지표 바로가기
  - 규칙은 `index.html` 의 `INSIGHTS` 에서 수정·추가 (일반 해석만, 종목·매매 표현 없음)
- **카테고리 탭**: 금리 / 물가 / 경기 / 시장·신용 / 환율 / 에너지 / 운임 / 비축·재고 / 금속 / 곡물 / ETF (탭 옆 점 = 가장 나쁜 신호)
- **지표 카드**: 현재 값, 직전 관측치 대비 변화(▲▼), 최근 3개월(월간 지표는 24개월) 미니 그래프, 신호등, 기준일·업데이트일·출처, 한 줄 해설
- **각 탭 맨 위 요약**: 상승·하락 개수, 경고·주의 개수, 가장 크게 움직인 지표, 관련 매크로 인사이트
- **카드를 누르면 상세 화면**
  - **인사이트** (전체 85개 지표, 규칙 기반)
    - 지금 상태: 직전 대비·1개월 변화·분포 위치(또는 평년 대비)·신호 자동 요약
    - 의미: 무엇인가 + 지금 상태(급등·상승·하락·급락·고점권·저점권·보합)에 맞는 해석
    - 함께 보면: 관련 지표와의 조합 규칙 중 지금 맞는 것만 표시 + 관련 지표 바로가기
    - 확인할 것: 발표 일정·변수
    - 문구는 `notes.js` 에서 수정·추가
  - 1주·1개월·1년 변화
  - **차트**: 1M / 3M / 6M / 1Y / 2Y / 5Y / 10Y (데이터 길이에 맞는 기간만 표시, 마지막 선택 기억)
    - 손가락으로 누르거나 끌면 그 날짜의 값이 표시됩니다 (키보드: 좌우 화살표)
    - 주의·경고 임계값이 차트 범위 근처에 있으면 노랑·빨강 가로선으로 표시

  - 자동 데이터 상태: 마지막 수집 시각, 실패한 지표와 이유
  - 값 직접 입력: 리튬·SCFI처럼 자동 소스가 없는 지표, 또는 자동 값 덮어쓰기 (같은 기준일이면 직접 입력이 우선)

## 4. 신호등·해설 판단 방식과 수정

모두 `index.html` 스크립트 상단 `CONFIG` 에 있습니다.

### 수준 신호 — 최근 분포 기준 (기본)
- `levelMode: 'percentile'`: 각 지표의 **최근 N년 값 분포에서 현재 위치**로 판단합니다.
  - 상위 10% 이상이면 주의, 상위 3% 이상이면 경고 (`percentile: { warn: 90, danger: 97 }`)
  - `dir:'down'` 지표(소비자심리 등)는 하위 기준
  - 비교 기간 `percentileYears`: 일간 2년, 주간 3년, 월간·분기 10년
  - 카드에 "2년 중 상위 4%"처럼 현재 위치가 표시되고, 상세 차트의 주의·경고선도 이 분포 기준 값으로 그려집니다.
- 고정 기준을 그대로 쓰는 지표 (`level.fixed: true`): 절대값 자체에 의미가 있는 것
  - 장단기 금리차(역전 <0), 삼의 법칙(0.5), 비농업 고용(감소 <0), 금융여건·스트레스지수(0 = 평균), GDP·산업생산·M2·소매판매(마이너스 여부), CPI·PCE·PPI(물가 목표), 실업률
- 이력이 부족한 지표(직접 입력 등)는 자동으로 고정값(`level.warn / danger`)을 씁니다.
- 전부 예전처럼 고정값으로 보려면 `levelMode: 'fixed'`.

### 변화 신호와 해설
- **신호등의 변화 신호**는 직전 관측치 대비(하루 급변)입니다: `change.warn / danger`
- **해설·체크리스트의 추세**는 일간·주간 지표면 최근 30일(`trendDays`) 변화로 판단합니다.
  하루 급등락(`change.danger` 이상)이 있으면 그것을 우선합니다. 월간·분기 지표는 직전 발표 대비입니다.
  - 1개월 보합 기준 = `change.flat × 3`, 1개월 급등 기준 = `change.danger × 1.5` (지표별 `trendFlat`, `trendBig` 로 조정)
- 최종 신호등 = 수준 신호와 변화 신호 중 더 나쁜 쪽

### 평년 대비 (계절성 큰 재고)
- 원유·휘발유·디젤 재고와 천연가스 저장량은 **같은 주의 과거 5년 평균** 대비 %로 판단합니다 (`level.seasonal`: −5% 이하 주의, −10% 이하 경고).
- 카드에 "평년 대비 −8.2%"로 표시되고, 상세 차트의 주의·경고선도 이 기준입니다.

### 오래된 데이터
- 자동 데이터: 수집이 7일 넘게 멈췄거나, **기준일 이후 주기에 비해 너무 오래 새 값이 없을 때** (`staleByFreq`: 일간 7일, 주간 14일, 월간 100일, 분기 220일. IMF 월간 원자재는 140일)
- 직접 입력: 입력 후 7일 (`staleDays`)
- 상세 화면에 경고 이유가 표시됩니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 설정에 "자동 데이터 파일 없음" | Pages Source가 **GitHub Actions**인지, Actions 실행이 성공했는지 |
| FRED 지표가 전부 ✗ "FRED_API_KEY 없음" | Secrets 이름이 정확히 `FRED_API_KEY` 인지 |
| FRED ✗ "HTTP 400" | 키가 틀렸거나 시리즈 ID 오타 |
| Yahoo ✗ "HTTP 429/403" | Yahoo 일시 차단 — FRED 대체 소스가 있는 지표는 자동 대체, 없으면 다음 실행에서 재시도 (이전 값 유지) |
| 배포 단계에서 "Branch is not allowed to deploy" | Settings → Environments → github-pages 의 배포 허용 브랜치에 main 포함 여부 |
| 화면이 예전 버전 그대로 | 앱 완전히 닫았다 다시 열기 (서비스 워커 갱신) |

ISM 제조업 PMI·S&P Global PMI 는 유료 라이선스라 2016년부터 FRED 에서 빠져 무료 API 로 받을 수 없습니다.
대신 같은 방식(“좋아졌다” 비율 − “나빠졌다” 비율)으로 만드는 지역 연은 제조업지수 3개(0 이상 = 확장)와,
85개 지표를 합친 시카고 연은 전미활동지수(0 = 평균 성장, −0.7 아래 = 침체 경고)를 씁니다.

### 자동 계산 지표 (이미 수집한 지표끼리 조합, 추가 비용 없음)
| 지표 | 계산 | 분류 |
|---|---|---|
| 한미 기준금리차 | 한국 기준금리 − 미국 기준금리 | 금리 |
| 한미 10년 금리차 | 한국 국고채 10년 − 미국 국채 10년 | 금리 |
| 미국 실질 정책금리 | 미국 기준금리 − 근원 PCE(최근 발표값) | 금리 |
| 저신용 추가 웃돈 | 하이일드 − 투자등급 스프레드 | 시장·신용 |
| 원화 환산 브렌트 | 브렌트 × 원/달러 | 에너지 |
| 브렌트−WTI 가격차 | 브렌트 − WTI | 에너지 |
| 금/은 비율 | 금 ÷ 은 | 금속 |
| 미국 원유 총재고 | 상업 재고 + 전략비축유 | 비축·재고 |

발표 주기·휴일이 다른 조합(금리차·실질금리·원화 유가)은 각 날짜에 상대 지표의 가장 최근 값을 씁니다.

### 계절성 처리
- **평년 대비 판단** (같은 주 과거 5년 평균과 비교): 원유·휘발유·디젤 재고, 천연가스 저장량, 정제 가동률, 휘발유 수요, 디젤 수요
  - 예: 가을 정비철에 가동률이 낮아도 평년 수준이면 경고하지 않음
- **계절 메모**: 천연가스·TTF·휘발유·디젤·크랙 스프레드·곡물·벌크/컨테이너/유조선/LNG선 운임·석탄·실업수당 청구 카드에 이번 달 계절 패턴을 한 줄로 표시 (`season.js`)
- 쿠싱 재고는 운영 최저선(약 2천만 배럴)이 중요해 고정 기준을 유지합니다 (평년 대비는 카드에 표시).
- 물가·소매판매·산업생산은 전년 대비, 고용·GDP·지역 제조업지수·CFNAI 는 발표처 계절조정 값이라 별도 처리하지 않습니다.

### 지난 브리핑 점검
- 아침 AI 브리핑은 직전 브리핑(ai.json)을 함께 읽고, 11개 분류마다 **↩ 지난 브리핑 점검** 한 줄을 씁니다.
  - "적중 / 일부 적중 / 빗나감 / 판단 보류 — 이유와 숫자" 형식
  - 근거는 지표별 `chg_since_brief`(지난 브리핑 작성 이후 변화, 새 발표가 없으면 null)
- 사이트의 분류별 브리핑·탭 상단과 텔레그램 브리핑(“↩ 지난 브리핑 점검”)에 표시됩니다. 메시지가 너무 길면 이 부분을 먼저 뺍니다.
